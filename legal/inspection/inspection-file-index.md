# How to use this file

- One folder per area. Every certificate, report, log and policy goes in its folder.
- Name files clearly: **what – company – date**, e.g. "Fire risk assessment – Falcon – 2026-11-16.pdf".
- When something arrives, save it here the same day and tick it off below.
- ✅ = in the folder · ⏳ = ordered / waiting · ❌ = still to arrange
